Qualified Piper Test

GitHub Pages 上で Qualified snippet を読み込むテストページです。

このページで Piper が表示されれば、Qualified の Experience 条件と snippet 設定は正常です。

表示されない場合は、DevTools の Console で window.qualified の値と qualified.js のネットワーク応答を確認してください。

チェックリスト
  • Qualified → Settings → Setup → Website domains にこのページのホスト名を追加
  • Automatic Experience の URL 条件を、このページの URL に合わせる
  • シークレットウィンドウで開いて過去 cookie の影響を排除
